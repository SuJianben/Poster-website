# 2026-08-21 产品尺寸指南弹窗

## 本次目标

让普通商品和自定义商品的 Size guide 按钮打开当前商品尺寸对比弹窗。

## 修改范围

- sections/main-product.liquid
- sections/custom-product-main.liquid
- snippets/product-size-guide.liquid
- assets/product-size-guide.css
- assets/product-size-guide.js

## 新增内容

- 根据当前商品 Size 选项动态列出可选尺寸。
- 使用 CSS 按真实宽高比例绘制尺寸示意图，并高亮当前已选尺寸。
- 支持遮罩、关闭按钮和 Escape 关闭，关闭后恢复按钮焦点。
- 手机端使用可滑动尺寸卡片，桌面端使用自适应网格。
- 打开弹窗时发送 `product_size_guide_open` 埋点事件。

## 调整内容

- 根据桌面端实际预览放大尺寸示例：弹窗最大宽度由 940px 调整为 1040px，桌面比例画布由 190px 调整为 230px，手机端由 180px 调整为 210px。
- 尺寸比例上限由 86% 调整为 96%，在继续保留各尺寸相对关系的同时减少无效留白。
- 根据红框视觉目标重做缩放方式：宽高分别归一化并使用平方根视觉比例，让小尺寸显著放大、最大尺寸接近填满卡片，同时保持尺寸递增顺序。
- 桌面比例画布进一步调整为 250px，并缩减卡片内部横向留白；手机端使用 160px 宽、230px 高的居中画布，避免大尺寸被拉成横向。
- 真实页面桌面端（1920×1080）实测：A4 为 77×104px，30×40 为 92×121px，50×70 为 119×160px，70×100 为 140×191px，100×140 为 168×226px；页面无横向溢出。
- 真实页面手机端（390×844）实测：弹窗为 375×492px，A4 为 70×95px，最大尺寸为 154×206px；尺寸列表可横向滑动，页面无横向溢出。

## 影响范围

- 影响普通商品页和自定义商品页的 Size guide 按钮。
- 不修改尺寸选择、变体、价格、装裱、上传、加购或购物车逻辑。
